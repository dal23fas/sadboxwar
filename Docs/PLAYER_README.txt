EARTH FRONTIER - DYNAMIC OPERATIONS (prototype build)

Run EarthFrontier.exe. Nothing else is needed.

Controls
  WASD move, Shift sprint, Space jump, mouse look, C first/third person
  E talk to NPC, F accept mission, X board/leave vehicle (stand next to it)
  Vehicles: W/S throttle, A/D steer/roll, Space/Ctrl collective (helicopter) / pitch (plane) / surface-dive (submarine), Q/E yaw
  1-4 load one item at a facility, R deliver what you carry, J mission journal, M map
  F5 quick save, F9 quick load, F10 Realism & Physics settings, F3 debug overlay, Esc menu / mouse

Everything is fictional game content. Placeholder graphics: vehicles are procedural silhouettes until real models are added.
Saves: %APPDATA%\Godot\app_userdata\EARTH FRONTIER - DYNAMIC OPERATIONS\efsaves
