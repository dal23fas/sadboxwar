# Asset Pipeline — πώς μπαίνουν «πραγματικά» μοντέλα στο παιχνίδι

Στόχος: οχήματα, κτίρια και χαρακτήρες που **μοιάζουν αληθινά** (σιλουέτα, αναλογίες, υλικά, φθορά) και είναι **πρωτότυπα σχέδια** — ρεαλιστική αισθητική, όχι αντίγραφα υπαρκτών στρατιωτικών μοντέλων (master prompt §01, §33, §47· supplement §4–§9). Έτσι το παιχνίδι έχει δική του ταυτότητα και καμία έκθεση σε trademark/design rights κατασκευαστών.

## 1. Πώς φορτώνονται τώρα

`godot/scripts/vehicle_visuals.gd`:

1. Αν υπάρχει `godot/assets/vehicles/<definition_id>.glb` → φορτώνεται **αυτό**.
2. Αλλιώς → procedural σιλουέτα ανά κλάση (φορτηγό με καμπίνα/καρότσα/τροχούς, ερπυστριοφόρο με ερπύστριες/χαμηλό πύργο, ελικόπτερο με άτρακτο/ουρά/ρότορα που γυρίζει, μονοκινητήριο με ψηλό φτερό/έλικα, σκάφος με πλώρη/πιλοτήριο/ραντάρ που γυρίζει, υποβρύχιο με sail/πτερύγια/έλικα).

Άρα: **ρίχνεις ένα .glb με το σωστό όνομα και παίζει αμέσως**, χωρίς αλλαγή κώδικα. Ονόματα: `utility_truck_fictional.glb`, `tracked_transport_fictional.glb`, `helicopter_light_fictional.glb`, `prop_trainer_fictional.glb`, `utility_patrol_boat_fictional.glb`, `research_submarine_fictional.glb` κ.λπ. (τα `definition_id` του content).

## 2. Συμβάσεις μοντέλου (για να δουλέψουν animation/κάμερες/συγκρούσεις)

| Κανόνας | Γιατί |
|---|---|
| Μονάδες: μέτρα, 1:1 κλίμακα | ο core μετρά σε μέτρα, οι ακτίνες αλληλεπίδρασης επίσης |
| Forward = **−Z**, Up = +Y, origin στο έδαφος κάτω από το κέντρο μάζας (πλοία/υποβρύχια: origin στην ίσαλο) | το `vehicle.gd` κινεί τον κόμβο προς −Z· η θάλασσα είναι y=0 |
| Κόμβοι που περιστρέφονται έχουν `spin` στο όνομα (`rotor_spin`, `prop_spin`, `radar_spin`) | το `_process` τους γυρίζει αυτόματα |
| Τροχοί έχουν `wheel` στο όνομα | περιστρέφονται με την ταχύτητα |
| Υλικά PBR (albedo/roughness/metallic/normal), ≤ 2048², 1 υλικό ανά μεγάλο κομμάτι | budget Phase 8: ≤ 60k τρίγωνα όχημα, ≤ 15k LOD1 |
| Ξεχωριστό mesh για κάμερα cockpit: κόμβος `cockpit_cam_anchor` (προαιρετικό) | Phase 3: η cockpit κάμερα κουμπώνει εκεί |
| Χωρίς πραγματικά σήματα, σειριακούς, σημαίες κρατών, ονόματα κατασκευαστών | fictional IP |

Εξαγωγή: Blender → glTF 2.0 Binary (.glb), +Y up, Apply transforms, include materials & textures (embedded ή δίπλα).

## 3. Πού βρίσκεις ποιότητα χωρίς να αντιγράψεις

- **Δικά μας σχέδια σε Blender** (προτείνεται για τα 6 βασικά οχήματα του slice): ξεκινάς από τις procedural σιλουέτες ως blockout, μοντελάρεις πάνω τους με αναφορά *γενικού τύπου* (ελαφρύ ελικόπτερο διάσωσης, 4×4 utility, περιπολικό σκάφος) και όχι συγκεκριμένο μοντέλο κατασκευαστή.
- **CC0 / CC-BY βιβλιοθήκες** για περιβάλλον, props, υφές: Poly Haven (υφές/HDRI, CC0), Kenney (props, CC0), Quaternius (low-poly, CC0), ambientCG (υλικά, CC0). Για οχήματα, CC0 μοντέλα *γενικού τύπου* είναι αποδεκτά· μοντέλα που αναπαράγουν συγκεκριμένο πραγματικό όχημα **όχι**, όποια άδεια κι αν δηλώνουν.
- **Αγορασμένα assets** (Phase 8): μόνο με άδεια που επιτρέπει εμπορική χρήση σε παιχνίδι και με έλεγχο ότι δεν αποτελούν replica προστατευμένου σχεδίου.
- Κρατάμε `godot/assets/LICENSES.md` με πηγή/άδεια/συγγραφέα **για κάθε αρχείο** (υποχρεωτικό για CC-BY).

Σημείωση για τη δική μου συμμετοχή: στο περιβάλλον αυτό δεν έχω Blender ούτε δίκτυο, άρα δεν μπορώ να παράγω ή να κατεβάσω μοντέλα. Μπορώ να γράψω Blender Python scripts (procedural modelling, π.χ. παραμετρικό ελικόπτερο/πλοίο) που τρέχεις εσύ στο Blender και εξάγουν .glb — αυτό είναι ο γρηγορότερος δρόμος για συνεπή, δικά μας μοντέλα. Ζήτησέ το όταν περάσει το Godot gate.
